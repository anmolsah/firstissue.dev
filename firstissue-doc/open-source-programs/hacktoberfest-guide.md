Beyond GSoC, the global open source ecosystem hosts several world-class contribution programs and fellowships that provide stipends, mentorship, and career acceleration.

## 1. Hacktoberfest Rules & Best Practices

Hacktoberfest is celebrated every October by DigitalOcean and community partners. Contributors must submit 4 accepted pull requests to participating public GitHub/GitLab repositories between October 1st and October 31st.

> [!WARNING] Avoid Spam Contributions
> PRs that only fix typos in README files, reformat spaces, or submit automated changes are marked as spam by maintainers. Two spam flags lead to permanent disqualification across Hacktoberfest.

## 2. Linux Foundation Mentorship (LFX)

The Linux Foundation Mentorship Program (LFX) provides 12-week paid remote internships across high-impact cloud native and systems infrastructure projects (Kubernetes, Hyperledger, GraphQL, OpenSSF, RISC-V).

- Runs 3 times a year: Spring (March-May), Summer (June-August), and Fall (September-November).
- Includes competitive location-based stipends.
- Apply directly via the LFX Mentorship portal with your CV and statement of intent.

## 3. Outreachy & MLH Fellowship

Outreachy offers $7,000 USD stipends for 3-month remote internships for underrepresented groups in tech. Major League Hacking (MLH) Fellowship pairs developers with open source projects like React, Babel, and Jest with weekly stipends and 1-on-1 mentorship.
