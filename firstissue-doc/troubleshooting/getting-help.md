Getting stuck is normal! Knowing where and how to ask for help will accelerate your learning and contribution success.

## Where to Ask for Help

1. Project's GitHub Discussions or Issues
2. Project's Discord/Slack community
3. Stack Overflow (for technical questions)
4. Reddit communities (r/opensource, r/programming)
5. FirstIssue.dev community Discord

## How to Ask Good Questions

- Be specific about what you're trying to do
- Include error messages and relevant code
- Mention what you've already tried
- Provide context about your environment
- Be polite and patient

### Good Question Template

```markdown
**What I'm trying to do:**
I'm trying to set up the development environment for [project name]

**What's happening:**
When I run `npm install`, I get this error: [paste error]

**What I've tried:**
- Cleared npm cache
- Deleted node_modules and reinstalled
- Checked Node.js version (v18.0.0)

**My environment:**
- OS: macOS 12.0
- Node.js: v18.0.0
- npm: v8.0.0
```

> [!TIP] Pro Tip
> Before asking, search existing issues and discussions. Your question might already be answered!
